Quick Assist on Windows

  1. Ask your technician for a 6-digit security code.
  2. Open Quick Assist: press Ctrl + Windows key + Q. Or select Start, type Quick Assist, and open it.
  3. Under Get help, type the code and select Submit.
  4. When it asks, select Allow so the technician can see your screen.
  5. Stay at your computer. To end the session at any time, close Quick Assist.
